Principais formatações

Negrito / Destaque

Nesta frase temos um termo em negrito utilizando a TAG <B> (NÃO SEMANTICA).

Nesta outra frase temos um termo em negrito utilizando a TAG <STRONG> (DE FORMA SEMANTICA).

Itálico / Enfase

Nesta frase temos um termo em itálico utilizando a TAG <I> (NÃO SEMANTICA).

Nesta outra frase temos um termo com enfase/itálico utilizando a TAG <EM> (DE FORMA SEMANTICA).

Texto Marcado

Podemos criar também um texto marcado utilizando a TAG <MARK>.

Para mudar a cor do marcador em um local especifico do texto utiliza-se o Style dentro do <MARK>.

Para mudar a cor do marcador geral de todo o codigo, utiliza-se o Style dentro do <HEAD>.

Texto GRANDE e PEQUENO

Estamos criando um texto grande e um texto pequeno nesse parágrafo.

Texto Deletado

Podemos marcar um texto como deletado para indicar que ele deve ser lido, mas não considerado.

Texto Inserido

Podemos marcar um texto como inserido para dar uma enfase e indicar que ele foi adicionado depois.

Existe também o sublinhado com a TAG <U> (NÃO SEMANTICA).
